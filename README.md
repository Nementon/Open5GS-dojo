# 5G Infrastructure Dojo

Welcome to the 5G Infrastructure Dojo! This repository provides a comprehensive learning environment for exploring and working with 5G infrastructure. The dojo is structured into modules, each focusing on specific aspects of 5G technologies and their practical applications.

## Overview
This dojo is designed to help you:
- Understand the architecture and components of 5G infrastructure.
- Deploy and test functional 5G core networks using open-source tools.
- Experiment with configurations and integrations to suit various use cases.

## Dojo Structure
The dojo is defined by [dojo.yml](./dojo.yml) and contains the following modules:

- **Infrastructure**: Focuses on deploying and configuring 5G core networks, including:
  - [Open5GS](./Infrastructure/open5gs): A module dedicated to the Open5GS 5G core network implementation.
  - [Free5GC](./Infrastructure/free5gc): A module for exploring Free5GC, another open-source 5G core network.


## Getting Started
1. **Clone the Repository**: Start by cloning this dojo to your local machine.
   ```bash
   git clone <repository-url>
   ```
2. **Explore the Modules**: Navigate through the modules and challenges to begin learning.
3. **Follow the Instructions**: Each module and challenge includes detailed instructions in their respective README files.

## Modules and Challenges
- [Open5GS](./Infrastructure/open5gs): Learn and deploy the Open5GS 5G core network.
- [Free5GC](./Infrastructure/free5gc): Explore and configure the Free5GC 5G core network.
